# 옛한글 자판 (TFTOP EDU)

갤럭시 등 안드로이드 휴대폰에서 쓰는 두벌식 자판입니다. **옛** 단추로 옛 한글 글자를 모아 씁니다.

| 옛 단추 + 글쇠 | 옛 글자 | 영어 소리 |
|---|---|---|
| ㅂ | ㅸ | v |
| ㅍ | ㆄ | f · ph |
| Shift + ㅅ | ᄾ | sh |
| ㅅ | ㅿ | z |
| ㅇ | ㆁ | ng |
| ㅎ | ㆆ | uh-oh의 끊김 |
| ㅏ | ㆍ | 짧은 u |
| ㅁ | ㅱ | (덤) |

## 설치
1. 이 저장소의 **Releases → latest → OldHangulKeyboard.apk** 를 휴대폰에서 내려받습니다.
2. 설치 중 "출처를 알 수 없는 앱" 허용을 묻으면 이번만 허용합니다.
3. 앱을 열어 ① 자판 켜기 ② 자판 고르기 순서로 누릅니다.

## 알아 두기
- 다른 앱(카카오톡 등)은 그 앱·휴대폰의 글꼴로 글을 보여 줍니다. 글꼴이 옛 한글을 모아 그리지 못하면 글자가 흩어져 보일 수 있습니다.
- 서명 키(keystore)는 이 개인용 앱의 업데이트를 위해 저장소에 포함했습니다.
